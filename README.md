# ייִדיש כּהלכה

כלי אישי ללימוד יידיש תקנית לפי כללי ייִוואָ (YIVO), לדוברת יידיש חסידית מהבית שרוצה להכיר את הכללים: כתיב, דקדוק ואוצר מילים. הממשק וההסברים בעברית.

## שני מסלולים

בראש מסך הבית יש מתג בין **הקורס** (ברירת המחדל) ל**אפליקציה המלאה**.

- **הקורס**: רק מה שנלמד ביידיש למתחילים בבר־אילן עד עכשיו. לכל שיעור יש דף עם היחידות הקשורות אליו, רשימת מילים ודיאלוגים לקריאה עם תרגום. "הנושא הבא" והסשן היומי בוחרים רק מתוך השיעורים הפתוחים.
- **האפליקציה המלאה**: כל מה שמתואר למטה, בלי שינוי.

### להוסיף שיעור חדש

הכול ב-`js/data/course.js`:

1. בערך חדש ב-`LESSONS`: מספר, כותרת, תיאור, ורשימת היחידות של האפליקציה שמכסות את השיעור.
2. רשימת מילים ב-`WORDS` (שורה לכל מילה: `יידיש|עברית|הערה`).
3. דיאלוגים וטקסטים ב-`TEXTS` (`body` ביידיש ו-`trans` בעברית).
4. להעלות את `OPEN` למספר השיעור.

חומר שהקורס מלמד ואין לו עדיין יחידה מקבל יחידה חדשה ב-`js/data/units*.js` (למשל `e5`, "יש ואין").

## מה יש בפנים

- **מסלול לימוד** של 29 יחידות בחמישה פרקים: כתיב תקני (אויסלייג), שם העצם, יחסות ותואר, הפועל, תחביר. בכל יחידה הסבר קצר, טבלאות, הערת "מהבית ← ייִוואָ" על ההבדל מהיידיש החסידית, ותרגול.
- **כל יחידה בצעדים קטנים**: קודם שתיים-שלוש שאלות "איך היית אומרת?" בלי הסבר ובלי ציון, ואז חלק אחד של הכלל בכל מסך ומייד תרגול שלו. בסוף תרגול מעורב. ההסבר המלא נשאר זמין בדף אחד. החלוקה לצעדים נמצאת ב-`js/data/steps.js`.
- **המין: דער · די · דאָס** (`js/gender.js`): שלושה שלבים לכל 276 שמות העצם. קודם חוקים שתמיד נכונים (סיומות, הקטנה, אנשים, עונות), אחר כך נטיות עם היוצאות מהן (לשון־קודש, ־ע), ובסוף המילים בלי סימן בקבוצות של שש. כל מילה ממוינת לאחת משלוש מגירות בצבע קבוע, נשלפת מהמגירה מהזיכרון, ונכתבת עם התווית. מילה שטועים בה פעמיים נכנסת ל"מילים העקשניות" וחוזרת בסשן היומי עד שלוש תשובות נכונות ברצף.
- **מהמין אל התואר והיחסות** (`דער · די · דאָס מההתחלה`): קבוצות של שש מילים, ודבר חדש אחד בכל צעד: המין, התואר, `דעם`, אחרי מילת יחס, `מײַן`/`מײַנע`. קודם בחירה ואז הקלדה, וצבע קבוע לכל מין.
- **אבחון** לפי פרקים: שתי שאלות לכל יחידה, אחת בבחירה ואחת בהקלדה. יחידה עוברת רק אם שתיהן נכונות.
- **הסשן של היום**: כפתור אחד בדף הבית, בסדר קבוע: חימום בחזרות ובתיקון טעויות; הדבר החדש של היום (הצעד הבא ביחידה הבאה: שאלה, הסבר קצר ותרגול); תרגול מעורב שמסתיים בפתגם; ולסיום משפט או שניים בכתיבה חופשית, עם בדיקת כתיב תוך כדי.
- **מהכרה להפקה**: תרגיל שנענה נכון בבחירה חוזר בפעם הבאה בהקלדה; תרגילי בניית משפט מעברית עם בנק מילים שיש בו גם צורות שגויות; הקלדת צירוף שלם (`דער טיש + גוט` ← `דעם גוטן טיש`).
- **שליטה לאורך זמן**: יחידה "יושבת" רק אחרי תרגול טוב בשלושה ימים שונים, והציון דועך אחרי שבועות בלי חזרה.
- **טעות לא נגמרת ב"הבא"**: אחרי טעות בהקלדה מקלידים את הצורה התקנית, וכל שאלה שטעית בה חוזרת פעם אחת כמה שאלות אחר כך.
- **"הצג את הכלל"** בכל תרגיל, בלי לצאת מהסבב, והצעת הסימנים (אַ, אָ, פּ, פֿ) תוך כדי הקלדה.
- **קריאה**: ארבעה טקסטים קצרים עם פירוש בהקשה על מילה, ניתוח דקדוקי של הצירופים (יחסה ומין) ושאלות.
- **התרגילים שלי**: מילים שתוקנו בבודק הכתיב, ותיקונים של המורה (Claude), הופכים לתרגילים אישיים.
- **דף לבדיקת מורה** (בכלים ← שאלות למורה): כל התוכן היידי בדף אחד להדפסה.
- **תרגילי שינון** שנוצרים מחדש בכל פעם: דער/די/דאָס ל-276 שמות עצם, יחסות ותואר, כתיב, האָבן/זײַן, בינוני, רבים, הקטנה, דרגת היתרון.
- **אוצר מילים** (כ-300 מילים בשבע קבוצות) בחזרה מרווחת, ואפשרות להוסיף מילים משלך.
- **תרגול יומי** מעורב ו**חזרה על טעויות**.
- **בודק כתיב** שעובד בלי אינטרנט: מדביקים טקסט בכל כתיב, והוא מסמן מה שונה מכתיב ייִוואָ ומציע את הצורה התקנית (מול מאגר של כ-1,500 צורות, ולפי כללי הכתיב).
- **מילון ונטיות**: מין, רבים, הקטנה, פועל עזר, בינוני ונטיית הווה, בחיפוש ביידיש (גם בצורה נטויה ובכל כתיב) או בעברית.
- **מעבדת יחסות**: בוחרים שם עצם ותואר ורואים איך התווית והסיומת משתנות.
- **משחקים**: בליץ דער/די/דאָס על הזמן, "מצאי את הטעות" (הגהה של משפט), השלמת פתגמים, והמרת משפטים מהווה לעבר ולעתיד.
- **פתגם היום** עם הערת דקדוק, יעד יומי ומפת התקדמות.
- **דרגה והתקדמות**: דרגה מ-1 עד 10 שנשענת רק על שליטה ביחידות (לא על כמות תשובות או רצף), ויכולה גם לרדת. בדף "ההתקדמות שלי": השוואה לשבוע ולחודש שעברו, דיוק בניסיון ראשון, ימי תרגול, והצעד שיקדם הכי מהר.
- **טבלאות** לעיון מהיר.
- **מורה (אופציונלי)**: חיבור ל-Claude לבדיקת כתיבה, לשאלות ולתרגילים נוספים. דורש מפתח API אישי; כל השאר עובד בלעדיו.

## איך מעלים לאוויר (GitHub Pages)

האתר סטטי לגמרי, בלי שלב בנייה ובלי שרת.

1. ב-GitHub: **Settings ← Pages**.
2. תחת **Build and deployment** לבחור **Deploy from a branch**.
3. לבחור את הענף שבו נמצאים הקבצים ואת התיקייה `/ (root)`, וללחוץ **Save**.
4. אחרי דקה-שתיים האתר זמין בכתובת `https://<שם-המשתמש>.github.io/Yivo/`.

בטלפון אפשר להוסיף את האתר למסך הבית ("הוספה למסך הבית"), והוא ייפתח כמו אפליקציה ויעבוד גם בלי אינטרנט אחרי הביקור הראשון.

## הרצה במחשב

אפשר פשוט לפתוח את `index.html` בדפדפן. או, עם שרת מקומי:

```bash
python3 -m http.server 8000
# ואז לפתוח http://localhost:8000
```

## איפה נשמרת ההתקדמות

בדפדפן של המכשיר (`localStorage`). אין שרת משלנו ואין הרשמה.

**סנכרון בין מכשירים (אופציונלי):** בהגדרות ← "סנכרון בין מכשירים". ההתקדמות נשמרת כקובץ פרטי (Gist) בחשבון ה-GitHub של המשתמשת. יוצרים פעם אחת קוד (token) עם הרשאת `gist` בלבד, מדביקים אותו בכל מכשיר, ומשם הסנכרון אוטומטי: בפתיחה, בחזרה לאפליקציה, וכחצי דקה אחרי התשובה האחרונה. ההתקדמות משני המכשירים ממוזגת, לא נדרסת.

**תזכורת יומית:** בהגדרות אפשר להוריד אירוע יומי חוזר ליומן של הטלפון, עם קישור לסשן של היום.

**גיבוי ידני:** הגדרות ← ייצוא לקובץ / ייבוא מקובץ.

## המורה (Claude)

בהגדרות מזינים מפתח API מ-[console.anthropic.com](https://console.anthropic.com/). המפתח נשמר רק בדפדפן ונשלח ישירות ל-Anthropic. התשלום לפי שימוש, ישירות ל-Anthropic. לא להזין מפתח במחשב ציבורי.

## מבנה הקבצים

```
index.html            המסגרת
css/style.css         העיצוב
js/text.js            נרמול טקסט יידי, נטיית תואר ופועל
js/data/units1-3.js   היחידות: הסברים ותרגילים
js/data/words.js      שמות עצם (עם מין), תארים, פעלים, רבים, הקטנות
js/data/spelling.js   זוגות כתיב: מוכר ← תקני
js/data/vocab.js      אוצר המילים
js/data/extra.js      מילות יסוד (לבודק הכתיב) ופתגמים
js/data/units4.js     תרגילי בניית משפט וטקסטים לקריאה
js/gen.js             מחוללי התרגילים
js/lex.js             הלקסיקון: בודק הכתיב והמילון
js/tools.js           בודק כתיב, מילון, מעבדה, בליץ, קריאה, דף לבדיקת מורה
js/track.js           מסלול המין: שש מילים בכל פעם, צעד אחד בכל פעם
js/store.js           שמירת התקדמות, חזרה מרווחת ומיזוג בין מכשירים
js/sync.js            סנכרון דרך Gist פרטי, וקובץ תזכורת ליומן
js/ai.js              החיבור האופציונלי ל-Claude
js/app.js             המסכים ומנוע התרגול
```

כדי להוסיף תרגיל ליחידה, מוסיפים שורה למערך `ex` שלה:

```js
['m', 'איך זע ___ מאַן. // רמז בעברית', 'דעם|דער|די', 'הסבר קצר'],
```

התשובה הנכונה היא תמיד הראשונה; הסדר מעורבב בזמן התרגול.

## הערה על הדיוק

התוכן נכתב לפי התקן של ייִוואָ (הכתיב של "תּקנות פֿון ייִדישן אויסלייג" והדקדוק המקובל בספרי הלימוד). במקומות שבהם המילונים חלוקים, בעיקר במין של מילים מסוימות, נבחרו רק מילים שהמין שלהן מוסכם. אם משהו סותר את מה שנלמד בקורס, המורה בקורס קובע, וכדאי לתקן את הקובץ המתאים.
